# 0299005 DATA ANLYS ML — Data Analysis with ML Exam Review

📊 Interactive, mobile-friendly study site for **0299005 Data Analysis with Machine Learning** (Chula MOOC Flexi). It teaches the course from zero with visuals and labs, and has a question bank that drills you in the real exam's proportions.

**Live site:** https://drasogo.github.io/0299005-DATA-ANLYS-ML/

## Exam format the site follows

50 multiple-choice questions; about half come from the course quizzes.

| Topic | Questions |
|---|---|
| Computer & digital systems | 5 |
| AI & machine learning | 10 |
| Python | 5 |
| Supervised learning | 15 |
| Unsupervised learning | 7 |
| Time series | 8 |

## Features

- **Lessons for 6 topics**, written for beginners. Each explanation sits right next to its figure, and the lessons include:
  - clickable step-by-step processes such as an ML project, k-means and ARIMA;
  - 38 interactive figures and labs such as a neural network, decision tree, ROC curve, PCA, bias–variance and a timing diagram;
  - glossaries and formulas with worked examples;
  - common exam traps, quizzes and flashcards.
- **Question bank of 379 questions**, including 251 real course quiz questions with their original choices.
- **Random exam** that draws a full 50-question set in the real topic proportions, or a 25-question short set. It prefers questions you have not seen yet and shuffles the options.
- **After every answer:** a recap of the concepts that question tests, the reason for the correct answer, and a link to the lesson.
- **Real exam mode, results by topic and saved progress**, the same as the PDPA site.

## Sources

The course quizzes (all 80 sets) and the course video subtitles. Answers to the quizzes are not published by the course; they were worked out by hand. This is a study aid.
